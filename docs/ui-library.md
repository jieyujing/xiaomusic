# 基于默认页面接口的媒体库 UI

根路径 `/` 提供手机优先的深色媒体库。前端是静态 HTML、CSS、JavaScript，沿用现有 FastAPI 路由、认证和播放逻辑，无需增加构建步骤。

## 默认页面接口映射

基准文件：`xiaomusic/static/default/index.html`、`md.js`、`setting.html`、`setting.js`。本次仅重构前端，不新增或修改后端接口。

| 默认页面能力 | 现有接口 | 新 UI 入口 |
| --- | --- | --- |
| 设备选择与配置读取 | `GET /getsetting` | 顶部音箱选择器，按 `mi_did` 和设备对象的 `did` 匹配 |
| 播放列表 | `GET /musiclist` | 播放列表页，保留目录、系统列表、自定义列表和收藏 |
| 当前播放列表 | `GET /curplaylist?did=…` | 当前列表页 |
| 歌曲信息 | `GET /musicinfo?name=…` | 歌曲、歌手、专辑、封面，按页加载；使用已存在的 `musictag=true` 可选参数 |
| 搜索 | `GET /searchmusic?name=…` | 搜索框；保留服务端搜索结果，补充已加载标签的本地匹配 |
| 播放指定列表和歌曲 | `POST /playmusiclist` | 全库、收藏或已有列表的播放 |
| 单曲点播 | `POST /playmusic` | 搜索结果、歌手／专辑分类、当前列表内的单曲点播 |
| 上／下一首、模式、定时停止 | `POST /cmd`，`GET /cmdstatus` | 播放器；等待异步命令结束，不把请求确认当作执行完毕 |
| 停止 | `POST /device/stop` | 底部主按钮与播放器 |
| 音量 | `GET /getvolume`、`POST /setvolume` | 播放器 |
| 收藏和取消收藏 | `POST /playlistaddmusic`、`POST /playlistdelmusic` | 播放器收藏按钮和媒体库收藏页签，使用同一个“收藏”列表 |
| 语音、匹配、设备等参数 | `GET /getsetting`、`POST /savesetting` | 设置表单；按分类编辑，统一提交实际变化的字段 |
| 小米扫码登录 | `GET /api/get_qrcode` | 设置；保留已登录提示和二维码流程 |
| 刷新列表 | `POST /api/music/refreshlist` | 设置中的扫描媒体库 |
| 播放状态推送 | `GET /generate_ws_token` → `/ws/playingmusic` | 播放状态与进度；切设备时关闭旧连接，隐藏页面时释放连接 |
| 完整配置 | `GET /getsetting`、`POST /savesetting`、`GET /device_list` | 新设置页完整覆盖默认页的 69 个参数和 13 个分类，支持设备勾选、搜索、校验和统一保存 |

WebSocket 不可用时，使用原有 `GET /playingmusic` 接口降级，不依赖新增接口。

## 能力边界

- “当前播放列表”显示 `/musiclist` 中对应列表的顺序。原接口不返回设备随机洗牌顺序，因此不宣称这就是实际下一首队列。
- 歌手／专辑是基于现有歌曲标签的浏览分类；分类和搜索结果中的歌曲使用原有单曲点播接口。没有“播放整个分类”的按钮，不创建临时歌单、不改写现有列表。
- 有声书沿用现有列表浏览，不新增续播数据模型。
- 音箱停止、从头播放与浏览器本机暂停续播是不同能力。新界面仅控制音箱，不展示只对旧页面 `<audio>` 有效的倍速／拖动定位／快进快退按钮。
- 上传、在线搜索、下载、代理和外部链接播放已被当前本地媒体策略禁止，新 UI 在管理页显示这些入口的禁用状态及原因，不发起在线操作。媒体根目录限制、语音匹配和播放逻辑保持不变。
- 普通媒体浏览不请求 CDN、遥测或远程图片；扫码登录只在用户主动点击时使用现有服务端返回的登录二维码。
- 仅设备选择和分页偏好写入浏览器本地存储，不保存账号密码、Cookie 或 WebSocket token。

## 验证

```sh
python -m unittest test.test_ui_contract test.test_local_media test.test_local_matching test.test_voice_playback -q
node test/ui/library.spec.cjs
```

macOS 运行旧媒体测试可设置 `TMPDIR=/private/tmp`，避免临时目录别名与解析后路径的比较差异。

`test_ui_contract.py` 将真实 FastAPI 路由绑定到隔离的业务替身，验证默认接口的请求／响应，包括真实 WebSocket 认证与状态消息，不连接小米或真实音箱。

浏览器测试使用真实静态资源和隔离 API / WebSocket 服务，验证：接口集合来自现有路由清单，设备名称按 `did` 正确匹配、播放与搜索参数、已有列表选择、当前列表顺序、停止／重播、收藏往返、定时指令、音量失败恢复、模式、语音开关、二维码状态、设备迟到响应隔离、分页和错误状态。检查 375、390、1024、1440px 竖屏及 844×390 横屏的主视图与播放器，并启用减少动态效果偏好。

可通过 `NODE_PATH` 指定 Playwright 包目录、`BROWSER_EXECUTABLE` 指定 Chromium 系浏览器、`UI_ARTIFACT_DIR` 指定截图目录。`LAYOUT_AUDIT_SCRIPT` 传入 ckw-design 的布局检查脚本，可生成带标记的截图和检查 JSON。

`UI_PREVIEW_ONLY=1` 启动示例数据预览，操作不影响真实音箱。预览不等于生产验收；现有 Docker 尚未更新。部署时只需要替换静态资源，无新增后端路由要求。

## 完整设置编辑器

`settings.js` 使用 `settings-schema.json` 构建完整表单。清单从原默认设置 HTML 自动提取，更新后可运行 `python scripts/generate_settings_schema.py`；契约测试检查新清单与原页所有 input/select/textarea 的 ID 集合完全一致，防止遗漏参数。

- 69 个字段分 13 类，以可折叠分组显示；支持中文名称和参数键搜索。设备勾选单独管理 `mi_did`。
- 仅用户改过的可编辑字段发送到原 `/savesetting`。数字、布尔值保留实际类型，JSON 语法错误在字段旁显示；跨分类或页面切换保留内存中的草稿，支持放弃更改和统一保存。
- 未修改的密码和 Cookie 不发送；密码留空或保留掩码遵循原接口“保持原值”的语义。既有凭据不显示明文、不写入浏览器存储；Cookie 可显式标记清除并随保存提交。
- 本地媒体根目录、服务地址、派生目录、被禁用的在线功能及固定语音策略显示当前值和只读原因，不静默删除参数，也不把无效修改发送到服务端。
- 扫码登录保留倒计时和过期提示；获取设备列表支持数组及对象两种返回形态。表单未勾选任何音箱时，设备选择更改不能保存。
- 保留扫描媒体库、标签刷新、浏览器偏好清理、临时文件清理和日志下载。清理操作需要明确确认；线上下载与 Cookie 上传保持不可用。
- 保存会重新初始化播放器，UI 提醒可能中断当前播放。本次测试对隔离服务保存，没有修改现有 Docker 的实际配置。

## 全功能迁移（仅本地媒体模式）

用户确认：保留全部管理入口，在线媒体功能禁用。新增“管理”主导航，包含歌单、媒体、设备、插件、高级、系统六类。全部路由的逐项对应关系见 [ui-route-coverage.md](ui-route-coverage.md)。

- 自定义歌单：创建、读取、重命名、删除、添加／移除本地歌曲、上下移动、保存／放弃排序；失败保留输入，未保存排序在切换管理分类时确认。
- 媒体：从本地库选择歌曲，编辑标题、艺术家、专辑、年份、流派、歌词、上传替换封面；保留未改字段。删除明确说明会删除磁盘文件，确认后执行，再读取媒体库确认文件已移出。原接口仍不能证明磁盘删除成功：若扫描后歌曲仍在，UI 报删除未确认。
- 设备：单独选择目标音箱，查看详细状态、停止、语音播报、自定义指令、本地 URL 播放。命令执行仍等待原 `/cmdstatus`；本地 URL 继续由原服务端校验。
- 插件：沿用原密码检查／验证流程；查看安装列表、禁用、确认卸载。安装、启用和在线导入保留禁用说明。
- 高级：读取现有高级配置、后台类型、口令平台、LXServer、订阅源状态；认证密钥不回显、不持久化。涉及在线媒体的修改、连接测试、同步与转换均显示禁用原因。密码检查是原 UI 行为，未新建或改变服务端授权模型。
- 系统：版本／检查新版本、文档与日志、确认模拟认证过期；历史下载任务可查看、暂停、停止、清理记录。继续／重新下载与新增下载禁用。仅显示原服务返回的活跃及近期任务，服务端不会返回所有历史记录。
- 原有 69 个设置字段、13 个分组继续在“设置”中完整覆盖。

运行 `python scripts/audit_ui_routes.py` 生成确定性清单。当前 102 条方法／路径声明（包含 1 条 OPTIONS）：55 条接入可用工作流，38 条在线／固定部署能力受限，7 条为页面、文档、状态、资源支撑，2 条批量信息接口由单曲详情工作流等价覆盖。新增未分类路由或过期映射会令审计失败。此数字是覆盖分类，不是生产执行次数。

`test/ui/management.cjs` 与原浏览器回归共用隔离服务，验证歌单 CRUD／排序、失败保留、标签修改与重试、取消／执行文件删除、设备参数、插件验证／禁用／卸载、任务暂停／停止、版本，以及 375/390/844/1024 宽度。所有请求与方法逐个匹配路由清单，禁止向 restricted 项发出请求。真实 FastAPI 契约测试验证对应 Pydantic 参数与调用形态。

运行时仍是静态资源部署，无新后端 API 或数据库变更。预览使用 fixture 数据；本轮未更换或重启实际 Docker，真实音箱及磁盘写入尚未作生产验收。
